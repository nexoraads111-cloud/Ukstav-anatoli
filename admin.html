Dopyty z webu

Prihláste sa a spravujte požiadavky z kontaktného formulára a „Zanechať číslo“. Údaje sú v Supabase (GitHub Pages nevie spúšťať PHP). Postup: SUPABASE.md.

Chýba konfigurácia Supabase. Skopírujte js/supabase-config.example.js → js/supabase-config.js a doplňte Project URL + anon kľúč. Potom v SQL Editori spustite supabase/setup.sql a vytvorte admin účet (Authentication → Users).

Prihlásenie správcu

Heslo je účet v Supabase Authentication (e-mail + heslo). Verejná registrácia musí byť vypnutá — účet založíte v Dashboard → Authentication → Users.
