# UKSTAV — сайт ukstav.sk

Статичний сайт (GitHub Pages) + Supabase для заявок, відгуків і фото.
Без збірки: відкрийте `index.html` або запустіть `python3 -m http.server`.

## Як влаштовано

| Що | Де |
|----|----|
| Головна сторінка | `index.html`, `styles.css`, `scripts.js` |
| Realizácie + галерея в одному блоці з фільтрами | `scripts.js` (`initWorks`); фото беруться з бази (таблиця `site_images`), тексти/ціни проєктів — `projects.js` |
| Світла / темна тема | `js/theme.js` (вибір запам'ятовується, за замовчуванням — як у системі), стилі — кінець `styles.css` |
| Сторінка проєкту | `project.html?id=project1` |
| Заявки з форми | зберігаються в Supabase **і** відкриваються у WhatsApp (`CONFIG.WHATSAPP_NUMBER` у `scripts.js`) |
| Відгуки клієнтів | форма на головній → модерація в адмінці |
| Адмінка | `/admin.html` (посилання на неї з сайту прибране навмисно) |
| База, права доступу | `supabase/setup.sql`, потім `supabase/seed-gallery.sql` (див. `SUPABASE.md`) |
| Автоматична доставка заявок на WhatsApp | `supabase/functions/notify-lead/` (Edge Function) + тригер `leads_notify` у `setup.sql` |

## Тема: світла / темна

Кнопка ☀/☾ у шапці на всіх сторінках. Вибір запам'ятовується в браузері; якщо його ще немає — береться тема системи.
На головному екрані **для кожної теми своє фото**: темна — слот `hero`, світла — слот `hero-light`.
Замінити їх можна без коду: `admin.html` → *Fotografie* → *Hlavný banner* → *tmavá téma* / *svetlá téma* → вибрати файл → *Uložiť*.
Зараз світла тема використовує світле фото `images/hero-light.jpg`.

## Realizácie а галерея — одна адмін-вкладка

Усе, що видно в блоці «Realizácie» на сайті й на сторінках проєктів, — це рядки таблиці `site_images` (`category = 'gallery'`).
Вкладка **Realizácie a galéria** в адмінці показує **усі** фото (134 початкових + завантажені):

* додати (можна багато файлів за раз; велике фото зменшується до 1800 px автоматично);
* змінити опис, **типи робіт** (можна кілька), **проєкт**, замінити сам файл;
* **Zobrazovať na webe** — сховати/показати фото без видалення;
* порядок: ⤒ *Na začiatok*, ↑, ↓ (на сайті — зверху вниз за цим порядком);
* видалити (файли з `images/` у репозиторії при цьому не стираються — лише запис у базі);
* фільтри: тип робіт (з лічильниками, є «Bez typu»), проєкт, видимість, пошук по опису.

Типи робіт: *Domy na kľúč, Rekonštrukcie, Kúpeľne a kuchyne, Obklady a dlažby, Strechy, Fasády a zateplenie, Chodníky a exteriér* (`WORK_TYPES` у `projects.js`).
Фото без типу успадковує типи свого проєкту; без проєкту і без типу показується лише у фільтрі «Všetko».
Сторінка проєкту (`project.html?id=…`) показує фото, у яких вибрано цей проєкт.

Якщо база недоступна, сайт бере резервну копію зі списків у `projects.js`, тож галерея не порожніє.

**Додати новий проєкт з описом, ціною й площею** — це поки що правка `projects.js` (новий блок `projectN`); фото потім прив'язуються до нього в адмінці.
Мініатюри для старих фото лежать в `images/thumbs/` (640 px); для нових завантажень сайт бере саме фото.

## Заявки → WhatsApp

Форма «Poslať požiadavku» і вікно «Zanechať číslo»:
1. записують заявку в таблицю `leads` (видно в адмінці → *Dopyty*);
2. **автоматично** надсилають її на WhatsApp +421 950 405 659: тригер у базі → Edge Function `notify-lead` → WhatsApp Cloud API. Потрібні ключі Meta в секретах Supabase — покроково в `SUPABASE.md` → «Заявки на WhatsApp автоматично». Біля кожної заявки в адмінці видно, чи дійшло повідомлення;
3. клієнту додатково відкривається WhatsApp із готовим текстом (запасний канал; якщо клієнт натисне «Надіслати», це друге повідомлення).

## Безпека

* У браузері лежить лише публічний ключ (`js/supabase-config.js`) — так і задумано.
* Усе, що змінює дані, дозволене лише акаунту зі списку `public.admin_users`. Чужий акаунт, навіть якщо зареєструється, не бачить заявок і не може нічого змінити чи завантажити.
* Відвідувачі можуть лише: дивитися фото й схвалені відгуки, надсилати заявку й відгук (відгук лишається «на модерації»).
* Старі PHP-скрипти (на GitHub Pages вони не виконувалися) видалені.

Деталі й налаштування в панелі Supabase — `SUPABASE.md`.
