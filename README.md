# UKSTAV — сайт ukstav.sk

Статичний сайт (GitHub Pages) + Supabase для заявок, відгуків і фото.
Без збірки: відкрийте `index.html` або запустіть `python3 -m http.server`.

## Як влаштовано

| Що | Де |
|----|----|
| Головна сторінка | `index.html`, `styles.css`, `scripts.js` |
| Realizácie + галерея в одному блоці з фільтрами | `scripts.js` (`initWorks`), дані проєктів — `projects.js` |
| Сторінка проєкту | `project.html?id=project1` |
| Заявки з форми | зберігаються в Supabase **і** відкриваються у WhatsApp (`CONFIG.WHATSAPP_NUMBER` у `scripts.js`) |
| Відгуки клієнтів | форма на головній → модерація в адмінці |
| Адмінка | `/admin.html` (посилання на неї з сайту прибране навмисно) |
| База, права доступу | `supabase/setup.sql` (див. `SUPABASE.md`) |

## Галерея з фільтрами

Кожне фото належить до типу робіт: *Domy na kľúč, Rekonštrukcie, Kúpeľne a kuchyne, Obklady a dlažby, Strechy, Fasády a zateplenie, Chodníky a exteriér*.
Список типів — `WORK_TYPES` у `projects.js`. Тип старих фото береться з `keywords` їхнього проєкту.

**Додати фото (без коду):** `admin.html` → *Fotografie* → *Realizácie a galéria* → вибрати файли (можна багато), позначити тип робіт, за потреби проєкт → *Nahrať*.
Великі фото з телефона зменшуються автоматично. Нові фото з'являються на початку галереї.

**Додати новий проєкт з описом, ціною й площею** — це поки що правка `projects.js` (новий блок `projectN` + фото в `images/`).
Мініатюри для сітки лежать в `images/thumbs/` (640 px, ім'я = ім'я фото з `.jpg`); без мініатюри сайт бере повне фото.

## Заявки → WhatsApp

Форма «Poslať požiadavku» і вікно «Zanechať číslo»:
1. записують заявку в таблицю `leads` (видно в адмінці → *Dopyty*, якщо Supabase недоступний — WhatsApp усе одно відкриється);
2. відкривають WhatsApp з готовим текстом (ім'я, телефон, опис). **Заявка приходить, коли клієнт натискає «Надіслати» у WhatsApp.**

Повністю автоматична доставка без дії клієнта потребує WhatsApp Business Cloud API (акаунт Meta, токен лише на сервері) — у цьому репозиторії її немає.

## Безпека

* У браузері лежить лише публічний ключ (`js/supabase-config.js`) — так і задумано.
* Усе, що змінює дані, дозволене лише акаунту зі списку `public.admin_users`. Чужий акаунт, навіть якщо зареєструється, не бачить заявок і не може нічого змінити чи завантажити.
* Відвідувачі можуть лише: дивитися фото й схвалені відгуки, надсилати заявку й відгук (відгук лишається «на модерації»).
* Старі PHP-скрипти (на GitHub Pages вони не виконувалися) видалені.

Деталі й налаштування в панелі Supabase — `SUPABASE.md`.
